The funniest honest error message a washing machine could show, in 200 characters or fewer. Entry for the make.fun bounty "The Funniest Honest Appliance Error".

The error (145 characters):

> ERROR: I ate one of your socks. I don't know which one, I don't know how, and I'm not giving it back. The rest of your laundry is fine. Probably.

## Run it

```sh
python3 main.py
```

This writes the error line to `/output/entry.txt` (validated: UTF-8, 1–200 characters, a single line). Standard library only, no dependencies.
